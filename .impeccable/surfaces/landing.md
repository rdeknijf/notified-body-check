## Direction contract

THESIS: The page is a registry card file. Each answer is an index card for one body: its number on the tab, dated entries in rows, and the status as a rubber stamp. It refuses the category default of a dark hero, gradient, and three feature cards.

OWN-WORLD: Warm card-stock ground, ruled entry lines, a manila tab carrying the four-digit body number, carbon blue-black ink for text and entries, one vermilion stamp ink owned outright for stamps and the primary action. Status is a stamped word, never a colour alone. Two type voices: a grotesk for prose and headings, a mono only for code, numbers, and data entries.

STORY: A visitor sees the question ("Is body 0123 notified under 2017/745 today?"), sees the stamped answer from live local data, copies the curl line, scans the endpoint register, copies an Atom feed URL, and reads the source and the limits.

FIRST VIEWPORT: Left column: service name, one sentence, two actions (Run a check, API docs). Right column: the check card with inputs above it, tab number, stamp, entries, as_of. Below the card: the equivalent curl line.
